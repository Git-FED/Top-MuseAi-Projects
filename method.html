03 / Methodology

What counts as
Muse AI?

The repo’s name, description, or topics must show it is about Meta’s Muse: muse.ai, Meta Muse, the Muse AI agent, or Hatch.

Deliberate exclusions

We exclude the Chinese companion/roleplay app called MuseAI, music/trading/hashing name collisions, the Muse EEG headband, Unity Muse, museum wordplay, and alternatives positioned against Muse.

How it updates

A GitHub Action runs scripts/update.py daily. The catalog data is stored in data/projects.json so the interface remains static-host friendly for GitHub Pages or Cloudflare Pages.
